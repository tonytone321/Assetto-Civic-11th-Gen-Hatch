# 2024 Civic Hatchback Sport Touring 6MT (Canada) — Assetto Corsa engineering database

Phase 1 (research only). The standing spec is `docs/SPEC.md`; the record format and file ownership are in `docs/DATA_FORMAT.md`.

## Where things are

- `vehicle_data/*.json` — one file per topic; every value is a sourced record with class, status, evidence and applicability. `user_measurements.json` is a fill-in template whose values win over everything else.
- `vehicle_data/_resolved.json` — the effective value per parameter (generated). `derived.json`, `gear_speed_table.csv`, `engine_curve.csv` — generated by code.
- `engine_curves/`, `references/manifest.json`, `audio/reference_database.json` — dyno run files, the visual reference catalog, the audio catalog.
- `docs/PHASE1_SCORECARD.md`, `docs/PHASE1_REPORT.md`, `docs/UNCERTAINTIES.md`, `docs/CONFLICTS.md`, `SOURCES.md` — generated from the data. `docs/SPOT_CHECK.md` — generated by a live re-check of the 20 key sources. `docs/CAPTURE_REQUESTS.md`, `docs/PLATFORM_CONSTRAINTS.md`, `audio/OBSERVATIONS.md`, `references/COVERAGE.md` — written documents.
- `docs/research_log/` — one short log per domain (what was opened, found and blocked).

## Rebuild and check

```bash
scripts/setup_env.sh                      # packages + browser CA trust (sandbox)
python3 scripts/make_user_template.py     # keeps any values you filled in
python3 scripts/resolve.py && python3 scripts/derive.py && python3 scripts/resolve.py
python3 scripts/validate_db.py --json cache/validate.json   # exit 1 on any failure
python3 scripts/make_report.py
python3 scripts/spot_check.py             # re-opens the 20 key sources live
```

`cache/` (downloaded pages, PDFs, photos) is git-ignored; the quote check in `validate_db.py` runs only where that cache exists.
