# Visual reference coverage — 2024 Civic Hatchback Sport Touring 6MT (Canada), Sonic Grey Pearl

Ratings: **sufficient** = enough legitimate, trim-confirmed references to model the area with confidence;
**thin** = references exist but are low resolution, wrong colour/market/gearbox, single-view or not downloadable;
**missing** = nothing usable found. Item ids refer to `references/manifest.json`.

No user photos exist yet (`user_supplied/` absent). Honda press images are only available as 928x522 previews
(higher resolutions return 403 / need a press login). Several good sources could not be downloaded:

Sport Touring owner thread (cdn.civicxi.com reset by the egress proxy), and YouTube (playback bot wall; not searched further).
